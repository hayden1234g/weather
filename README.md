# Weather

A simple National Weather Service forecast page. Search a ZIP code or "City, ST" (or use your location), see current conditions, alerts, and the 7-day forecast; tap a day for its hourly forecast.

Single static `index.html`, no backend or API keys. Data: api.weather.gov (forecast, hourly, gridded data, alerts, observations), api.zippopotam.us (ZIP lookup), Open-Meteo geocoding (city lookup).

Live: https://hayden1234g.github.io/weather/
